# Keyboard map

`us.xkb` is the self-contained US evdev map generated by Ubuntu `xkbcomp` (x11-xkb-utils 7.7+9build1) from xkb-data 2.46-2 in the pinned Ubuntu runtime:

```xkb
xkb_keymap {
 xkb_keycodes { include "evdev+aliases(qwerty)" };
 xkb_types { include "complete" };
 xkb_compatibility { include "complete" };
 xkb_symbols { include "pc+us+inet(evdev)" };
};
```

Run `xkbcomp -w 0 -xkb source.xkb us.xkb` in that runtime. Package notices are preserved in `licenses/XKB-DATA-COPYRIGHT`. CMake embeds the text; the bridge shares a sealed, NUL-terminated keymap with Wayland clients.
