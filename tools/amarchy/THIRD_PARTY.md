# Third-party code

Amarchy reuses the repository's [Android Steam](../androidsteam/THIRD_PARTY.md) pinned PRoot build and adapts its Wayland/Android display and input implementation for a nested desktop. The software bridge and Linux memory allocator are Amarchy-owned; Steam, authentication, Proton and game-control features are excluded.

- PRoot: pinned Termux/DroidDeck-derived build and session-cleanup patch, GPL-3.0; attribution and corresponding-source references are in Android Steam's notice.
- Wayland 1.24.0, Wayland protocols 1.45, libffi 3.4.6 and the self-contained US keymap: pins and notices are retained from Android Steam. The desktop bridge uses modern seat/compositor/xdg-shell protocols and presents memory-backed Mesa frames. Amarchy does not load an Adreno driver.
- Runtime packages: exact versions, URLs, checksums, dependencies, upstreams and declared licenses are in `runtime/packages.lock.json`, also included in the environment. Package-provided licenses, development files and notices remain in the archive. Packaging sources: https://github.com/archlinuxarm/PKGBUILDs and https://github.com/omacom/omarchy-pkgs. `profile.lock.json` records every upstream default's disposition; `android-profile.json` records Android omissions and provider choices. Omarchy's patched Quickshell provides its Qt 6.11 loader integration, and the ARM64 Omarchy Neovim package supplies the offline plugin cache.
- The Amarchy-owned software DRM allocator shares memory-backed buffers with Mesa's existing kms_swrast/LLVMpipe renderer. Source is in `native/software_drm.c` (GPL-3.0-only). It uses neither root nor hardware GPU access.
- Aquamarine 0.15.1 (BSD-3-Clause): rebuilt from the checksum-pinned source with an ABI-preserving nested-Wayland patch. It flushes output creation, publishes ready outputs, queues configure acknowledgements before rendering, and finishes software rendering before presenting shared memory. The original package's headers match the source headers. Build-only hyprwayland-scanner 0.4.5, pugixml 1.15 and GCC 16.1.1 headers are pinned in `native/aquamarine/sources.lock.json`; the patched backend is reproducible with NDK 29.
- Omarchy (MIT): revision `9480d1b6a98156314dbabe6bfef08f39f8b9cd07`, checksum-pinned in `runtime/omarchy.lock.json`. Its complete source, shell, menus, themes, graphical assets, defaults and license ship in `/usr/share/omarchy`. The user seed comes from those defaults and package-owned configuration. Explicit source adaptations in `runtime/build.py` remove journald from shell launch, launch browsers directly through Android's session owner, and serialize theme retint hooks to respect Android's child-process budget. The small `uwsm-app` adapter runs commands inside the existing Android-owned session. Full-OS boot/hardware provisioning is not executed.
- Apache Commons Compress: Apache-2.0. Environment decompression uses Android's platform gzip implementation; the Java XZ dependency has been removed.

Amarchy is an independent Android adaptation. The software allocator also keeps Hyprland's long private instance sockets in a path-keyed abstract namespace so PRoot can connect its control tools, and makes Qt use named atomic temporary files where Android blocks publication of unnamed files. Android's platform adapter disables unsupported upstream system controls and locking, supplies browser flags required by the sandbox, and preserves compatible shell configuration. User files and services remain in Android's app sandbox.
