# Third-party code

Amarchy reuses the repository's [Android Steam](../androidsteam/THIRD_PARTY.md) pinned PRoot build and adapts its Wayland/Android display and input implementation for a nested desktop. The software bridge and Linux memory allocator are Amarchy-owned; Steam, authentication, Proton and game-control features are excluded.

- PRoot: pinned Termux/DroidDeck-derived build and session-cleanup patch, GPL-3.0; attribution and corresponding-source references are in Android Steam's notice.
- Wayland 1.24.0, Wayland protocols 1.45, libffi 3.4.6 and the self-contained US keymap: pins and notices are retained from Android Steam. The desktop bridge uses modern seat/compositor/xdg-shell protocols and presents memory-backed Mesa frames. Amarchy does not load an Adreno driver.
- Runtime packages: exact versions, URLs, checksums, upstreams and declared licenses are in `runtime/packages.lock.json`, also included in the environment. Package-provided licenses and notices remain in the archive. Arch Linux ARM packaging sources are available from https://github.com/archlinuxarm/PKGBUILDs.
- The Amarchy-owned software DRM allocator shares memory-backed buffers with Mesa's existing kms_swrast/LLVMpipe renderer. Source is in `native/software_drm.c` (GPL-3.0-only). It uses neither root nor hardware GPU access.
- Aquamarine 0.15.1 (BSD-3-Clause): rebuilt from the checksum-pinned source with an ABI-preserving nested-Wayland patch. It flushes output creation, publishes ready outputs, queues configure acknowledgements before rendering, and finishes software rendering before presenting shared memory. The original package's headers match the source headers. Build-only hyprwayland-scanner 0.4.5, pugixml 1.15 and GCC 16.1.1 headers are pinned in `native/aquamarine/sources.lock.json`; the patched backend is reproducible with NDK 29.
- Omarchy (MIT): revision `9480d1b6a98156314dbabe6bfef08f39f8b9cd07`, checksum-pinned in `runtime/omarchy.lock.json`. Its code/defaults/theme metadata and license ship in `/usr/share/omarchy`. Amarchy loads its Lua bootstrap, helpers, look/feel and tiling defaults, with Android session/input/launch adaptations and Everforest terminal colors. Full-OS boot/hardware service setup is not executed inside the Android app.
- Apache Commons Compress: Apache-2.0. Environment decompression uses Android's platform gzip implementation; the Java XZ dependency has been removed.

Amarchy is an independent Android adaptation. The software allocator also keeps Hyprland's long private instance sockets in a path-keyed abstract namespace so PRoot can connect its control tools. User files and services remain in Android's app sandbox.
