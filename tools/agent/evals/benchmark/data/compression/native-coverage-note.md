The native runner must replace <workspace> with its isolated directory and normalize returned paths consistently. Exact allowedCommands permit only the authored verification command; no UI, network publishing, or outside writes are authorized. Transcripts live in homeState.transcripts; current message timestamps follow the seeded exchanges so HomeRouter can include their completed replies. The coordinator run tests routing, not actual queue execution. These cases do not validate real UI/browser interaction, authentication, external services, hosted search, production skill catalogs, persistent history resumption, or suggestion timing/caching. Fixture contents and assertions were finalized before any outputs; reviewers should judge equivalent outcomes by each actual request.
