# A1R

![A1R banner](assets/a1r-banner.png)

> A small personal runtime for ongoing work.

A1R is a lean, local-first runtime for sessions, tools, memory, and execution—available wherever you work.

A1R is built around a few simple ideas: a small core, persistent memory, practical gateways, and lightweight decision-making.

```text
input → decide → act → remember
```

## Planned

- CLI
- native desktop apps
- persistent sessions
- deep links to existing sessions
- local memory
- tools and gateways
- lightweight task workers
- model and workflow routing
- direct execution with minimal ceremony

## Principles

- small enough to understand
- local-first
- one core runtime, many interfaces
- cheap components, strong composition
- persistent context
- no unnecessary abstractions

A1R is an independent experiment in building a useful personal computer companion without turning it into a platform.

> Small core. Persistent context. Useful work.
