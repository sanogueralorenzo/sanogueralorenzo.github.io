# Open links and windows

Links use regular tabs. **Option-click** opens a link in a selected tab; **Command-click** or a middle click opens a background tab. Add **Shift** to select the new tab. Moving tabs to another Space always follows them there. A link leaving a pinned or saved tab’s site opens a new selected tab, keeping the saved page in place.

Links and documents from other apps open as regular tabs in the current Space of your most recent regular browser window. If no regular window is open, Crest reopens the most recently used one. Private Windows do not receive external links.

## Sign-in popups

A website’s popup opens as a regular tab in its opener’s Space and engine. Crest adopts the actual page, preserving its opener, signed-in profile, redirects, and scripts. The popup can communicate with its opener and close its own tab when sign-in finishes. Popup permission rules still apply.

System authentication requests use a dedicated sign-in window until the requesting app receives its callback. These windows have no tab promotion or inactivity timer.

## Shared windows and Blank Window on Mac

Use **Command-N** for another window onto your shared Spaces and tabs. Each window keeps its own selected Space and tab. Organizing or closing a tab changes the shared workspace; closing the window itself keeps your tabs available in the other windows.

When two windows show the same tab, the focused window holds the live page and the other displays its preview. Focus the other window to continue there with the same page state.

Use **Option-Command-N** for a **New Blank Window**: a disposable workspace using the current Space’s signed-in session, extensions, and settings. Its tabs, folders, history, and archive stay out of iCloud sync and are discarded when it closes.

Drag a tab outside the window to move it into a blank window at the drop location. Move a tab back into a normal window to keep it in the shared workspace.
