Install from the Chrome Web Store

Crest for Mac installs Chrome extensions from the Chrome Web Store. Extensions run on Chromium pages. Pages you open in WebKit, and Crest on iPhone and iPad, run no extensions.

Before you add it​

Switch to the Space that should own the extension. Its package, enablement, permissions, storage and pinning stay separate from every other Space and device.

Install the extension​

  1. In a normal Crest window on Mac, open the extension's page in the Chrome Web Store.
  2. Select the store's own button, which reads Add to Crest. You can also open Site Controls and select Install Extension….
  3. Wait while Crest downloads the package from Google's update service. Chromium checks the publisher's signature and the extension's ID before the review appears.
  4. In the review sheet, check the extension's name and the Verified Chrome Web Store package label.
  5. Open Review Access and Compatibility and read the permission warnings. Where the extension allows it, turn on Withhold website access until I grant it.
  6. To install the same package in more Spaces, select Install in other Spaces… and choose them.
  7. Select Add Extension, then Done.

Once installed, the listing's button reads Added to Crest, and it offers Remove from Crest for this Space.

Use it after installation​

  • Open Site Controls beside the address field to find the extension's action, and pin it if you want it in the Space's extension strip. See Pin extensions and use popups.
  • Open Crest Settings, select the Space in the sidebar, then select Extensions. Expand the extension to turn it on or off, open its settings, manage its permissions, copy it to other Spaces, or remove it.
  • If the extension has keyboard commands, see Set extension keyboard shortcuts.

Updates​

Chromium updates Chrome Web Store extensions on its own and checks each update's signature and permissions, as Chrome does.

When you can't install​

  • Private windows keep the store's own behavior and do not offer Add to Crest.
  • A locked Space, or one that has been deleted, cannot receive an extension or a copy.
  • Crest does not install Firefox add-ons or Safari Web Extensions. Look for the extension's Chrome version.
