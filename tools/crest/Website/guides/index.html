Help

Articles for Crest on Mac, iPad, and iPhone.

Crest brings Chromium and WebKit together on Mac. Read the engine and upgrade guide for website sign-ins, extensions, and choosing an engine. iPhone and iPad continue to use WebKit.

Install extensions​

Install from the Chrome Web StoreAdd a Chrome extension from its store page to the current Crest Space.Firefox add-onsCrest does not install Firefox add-ons. Use an extension's Chrome Web Store version instead.Safari Web ExtensionsCrest does not scan Mac apps for Safari Web Extensions. Use an extension's Chrome Web Store version instead.
