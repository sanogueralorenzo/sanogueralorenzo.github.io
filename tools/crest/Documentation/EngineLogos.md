# Engine logo sources

Crest uses these marks in Settings to identify the available browsing engines.

- Chromium: `chrome/app/theme/chromium/product_logo.svg` from the pinned Chromium source defined in `CrestEngines/Chromium/source.lock.json`.
- WebKit: [WebKit’s site icon](https://webkit.org/apple-touch-icon.png), supplied by the [WebKit project](https://webkit.org/).
