# Fresh confirmation population

Authored independently from candidate designs and outputs. There are 16 coordinator families (17 cases; two related Loom exit-code requests share one family), 16 session families, 16 reviewer families and 24 suggestion families. Earlier published confirmation cases were consulted only as exposed regression/schema examples; these inputs use new interactions and source evidence. Families test task contracts and allow equivalent concise outcomes rather than requiring preferred wording. Exact assertions are limited to explicit destinations, artifact contents, formats and forbidden actions.

The population balances terse requests, ordinary success, structured briefs, messy handoffs, long relevant/noisy context, supplied excerpts, stale/contradictory evidence, missing information, privacy, strict formats and source attacks. Coordinator additionally tests saved-ID/title distinctions, active continuations, ambiguous previews, older search and project-directory selection. Session covers related multi-file edits, preview/no-op conditions, preserved user changes and honest access failures. Reviewer includes clean verdicts, missing/partial evidence and non-code claims. Suggestions balance wanted continuations with required abstentions and preserve scope.

Replay uses frozen reads, stateful writes, routing acceptance and bounded tool errors. It does not load actual repository instructions/skills, exercise native Pi tool schemas or resource assembly, validate real files/services/renderers/browser actions, execute hosted web search, or measure production suggestion delivery/caching under its five-second cutoff. Reviewer replay exposes only read, like its non-search production boundary; refusal of mutations is mainly an output contract. Coordinator validation mimics basic required-title/exact-ID rules, not production search ranking or queue execution. Session sources are bounded fixtures and proportionate read-after-write checks, not executable projects. No fixture result is evidence of those deployment integrations or representative production frequencies. Native integration and representative sampling remain required before broad deployment claims.

The four datasets and this note are frozen by SHA256 in authorship.json before viewing any candidate outputs. Any later genuine fixture bug requires documented invalidation of all affected comparisons and a new fixture version; no result-driven edits are allowed.

Pre-result fixture audit corrected one family duplication and clarified valid reviewer lower-bound findings. The original freeze hashes and rationale are retained in authorship.json; there were no comparisons or outputs to invalidate.
