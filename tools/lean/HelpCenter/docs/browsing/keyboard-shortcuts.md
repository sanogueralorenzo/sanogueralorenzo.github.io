# Keyboard shortcuts

These are the current defaults. On Mac, open **Settings → Shortcuts** to search the whole catalog, record a new shortcut, clear an assignment, inspect conflicts, or restore the default. Commands marked **Unassigned** remain available from the menu and command palette.

## Windows and navigation

| Action | Default |
| --- | --- |
| New Window | Command-N |
| New Blank Window (Mac) | Option-Command-N |
| New Tab | Command-T |
| New Private Window | Shift-Command-N |
| Close Current Tab or Window | Command-W |
| Close Window | Shift-Command-W |
| Open Location / command palette | Command-L |
| Back | Command-[ |
| Forward | Command-] |
| Reload Page | Command-R |
| Stop Loading | Command-. |
| Reload from Origin | Shift-Command-R |

On Mac, **Command-L** opens the address editor while keeping a collapsed sidebar collapsed.

For a saved or pinned tab, **Command-W** returns to its saved URL first. At that URL, it puts the page to sleep and switches to another active tab, keeping the saved tab in the sidebar. Saved tab rows show the same shortcut beside their return arrow or minus button.

| Previous Space | Option-Command-Left Arrow |
| Next Space | Option-Command-Right Arrow |

Tap **Control-Tab** to jump to the tab you used last. On a Mac, hold it to see your recent tabs: press **Tab** or the arrow keys to move through them and let go of **Control** to switch. **Control-Shift-Tab** goes to the tab you used longest ago. A split appears as one card. To skip the previews, turn off **Show recent tabs while switching** in Settings > Tabs.

## iPad hardware keyboards

iPad uses Crest’s shipped defaults for the commands available on that platform. Hold the Command key to inspect commands exposed by the current menu context. Full shortcut rebinding is a Mac feature.

New Blank Window is a Mac command.

## Context-only keys

**Escape** dismisses the command palette and other transient panels when dismissal is available.

## Resolve a conflict on Mac

Search for either command in **Settings → Shortcuts**, select the row, and record a different key combination. Crest shows collisions before the replacement becomes part of your command map. Clearing a shortcut makes the action unassigned; resetting restores the shipped default.
