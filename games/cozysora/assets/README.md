# Cozy Sora preview

`seabreeze_village.png` is a 1280 × 720 in-game capture rendered by this project's procedural Godot scene at its `coast` scenic viewpoint. It is owned by the project and used by the destination selector. It contains no imported external visual assets.

To refresh it after an intentional map improvement, capture that viewpoint with the command in the project README, inspect the result, and replace this image. Keep the registry preview aligned with the playable destination.
