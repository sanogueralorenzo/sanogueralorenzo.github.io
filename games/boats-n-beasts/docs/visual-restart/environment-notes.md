# Procedural 3D environment

`BoatsNBeasts.EnvironmentArt3D.Build(Core.Place)` builds Harbor, Island and Rock scenery at the local origin. Place the returned node at `(place.Position.X * .01, 0, place.Position.Y * .01)`. Other place kinds return an empty node. `Cottage()` builds the same architecture at unit scale, rooted at its floor, for native comparisons.

All geometry is deterministic C#, with no imported meshes or textures. Sand, rocks, architecture, foliage and restrained surf share one indexed mesh surface. A second surface uses `EnvironmentShallows.gdshader` for static turquoise seabed, rounded submerged stones and irregular alpha falloff. Materials are shared; meshes belong to each streamed place. The ocean remains at y=0; the transparent shelf is at y=.004–.021. Shelf extent is capped at 1.55 times the simulation collision radius and does not affect collision.

The cottage has rounded wall corners, raised foundation, an arched entrance, window trims/mullions, overlapping curved roof tiles, ridge caps and an open-topped chimney. Harbor docks have dimensional boards, beams, posts and cut post tops. Cliff masses use convex polyhedra built from intersections of unequal tilted fracture planes. Their irregular edges/corners are beveled, their albedo varies spatially, and overlapping masses have different extents rather than uniform horizontal tiers. Foliage uses closed folded leaf geometry, curved tapering fronds and segmented trunks.

Debug and Release builds passed with zero warnings/errors after the latest geometry refinement. Earlier native integration identified invalid leaf-tip normals from a fractional power of a slightly negative floating-point `sin(pi)`; the input is now clamped, and degenerate faces are rejected before normalization. Main verified the corrected native sample had no warnings/errors. Main also corrected vertex color interpretation to sRGB. The initial smooth pale shelf and straight-sided polygonal rock generator were rejected and replaced.

Final native visual acceptance, shader compile verification for the latest refinement, gameplay checks and sustained combined performance remain owned by the main integration task. This note does not claim those checks have passed.

The rounded cuboid iteration was rejected in native gameplay: it read as toy blocks, and the broad shelf still formed a turquoise necklace. The replacement is the fractured-plane generator above, with shelf width concentrated in unequal coves, stronger large-scale transparency breakup, and fewer low-contrast submerged stones. Builds alone do not establish that these changes solve the visual gaps. The native scene still needs direct comparison with Direction B for broad fractured rock silhouettes, naturally connected shallow water, and sufficient surface richness at gameplay scale.
